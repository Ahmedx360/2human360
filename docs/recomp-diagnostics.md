## How the original failures were solved
The PE's section headers are shifted by +0x5000 for .text/.embsec_ (RVA == file offset for code, .pdata, tables).
Fixed in the loader patch (`tools/patches/xenonrecomp-pe-loader.patch`). Earlier symptoms (runaway analysis,
OOM, fake "unrecognized" VMX instructions, garbage jump tables) were all caused by that mapping error.
